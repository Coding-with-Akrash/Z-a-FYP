Tip: Higher quality media yields more accurate results. Clear faces and good lighting improve detection.
Step 2
Ensemble Analysis
Multiple AI models work together

Our system combines three AI models, each contributing to the final verdict:

Model Weight Specialty
EfficientNet-B0 35% Visual artifacts, facial inconsistencies
ResNet-18 35% Texture anomalies, patterns
Feature Extractor 30% Bio signals, frequency, texture
Step 3
Review Results
Detailed breakdown and interpretation

After analysis, you'll receive a comprehensive report:

  • Verdict: FAKE or REAL with confidence percentage
  • Model Scores: Individual predictions from EfficientNet and ResNet
  • Feature Analysis: Bio signals, visual artifacts, frequency, and texture percentages
  • Temporal Data: For videos: frame count, consistency score
Need help? Use the AI Assistant to ask questions about your results!

FAQ

Common questions

How accurate is BioSecure?

Our ensemble model achieves 97% detection rate and 93% accuracy on diverse datasets, significantly outperforming single-model approaches.

Is my data stored?

No. All processing is done in real-time and no files are stored on our servers. Your privacy is guaranteed.

What file types are supported?

Images: JPG, PNG, JPEG. Videos: MP4, AVI, MOV. Maximum file size: 50MB for images, 100MB for videos.

How long does analysis take?

Typically under 2 seconds for images and 5-10 seconds for videos, depending on length and complexity.

Best Practices

Image Best Practices
  • ✓ Use high-resolution images
  • ✓ Ensure faces are clearly visible
  • ✓ Avoid heavy compression artifacts
  • ✓ Natural lighting preferred
Video Best Practices
  • ✓ Longer videos = more accurate
  • ✓ Keep file size under limit
  • ✓ Include both face and upper body
  • ✓ Stable camera movement helps
Understanding Confidence

Confidence scores reflect model agreement:

  • 90-100%: Very high certainty
  • 70-89%: High certainty
  • 50-69%: Moderate certainty
  • <50%: Low certainty
